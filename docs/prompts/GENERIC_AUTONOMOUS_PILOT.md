# Generic AgentReady autonomous pilot — portable template

AgentReady aims to deliver a reusable, reproducible setup-and-daily-brief workflow, not duplicate an agent framework. An executor with terminal access should validate the project's unit tests, run synthetic fixtures, audit its own already-authenticated connector capabilities and produce a factual report. It should use the existing agent/CLI in its environment; Hermes is optional. Work only in an isolated workspace and never export private or employer data to a public repository.

Required report: provider, CLI version, auth/scopes state (without credential material), commands tested, whether live or fixture, outcome PASS/PARTIAL/BLOCKED, GitHub publication outcome, proof of CI if published, and next steps.

Only register a durable scheduled job if explicitly asked and able to verify job ID/status. Do not claim background completion from a chat-only session.
