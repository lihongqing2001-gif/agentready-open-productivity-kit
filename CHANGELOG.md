# Changelog

## 0.2.0 — 2026-10-12

- Added interactive per-adapter wizard, which writes only local, nonsecret `enable` and `disable` settings.
- Added capability-to-provider coverage map, distinguishing provider *selection* from verified authentication.
- Added offline Markdown onboarding reports and create-only, user-private writes.
- Added fixed-route, opt-in HomeBox and NocoBase connection probes; no network by default, TLS and explicit opt-in for remote services.
- Added synthetic loopback HTTP tests (status, optional HomeBox token auth, NocoBase MCP initialize, rejection of paths/credentials, dry-run).
- Preserved v0.1 native-first installation, four skills, four profiles and dry-run-first defaults.
